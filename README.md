A bush-plane airlift across the Ember Isles, a volcanic archipelago at golden hour: thread 18 rings through three sorties, land on three island strips, spend spare parts on four aircraft upgrades, and chase the six violet bonus rings off the route.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the game plays offline in a desktop browser, no network requests, no build step.
